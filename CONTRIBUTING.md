# Contributing

Thanks for helping improve Pinch & Snap.

## Before opening an issue
- Search existing issues for duplicates.
- Use a recent stable version of Chrome.
- Reproduce the issue with extensions that may interfere disabled, if practical.
- Never include passwords, cookies, private URLs, or personal data in screenshots/logs.

## Bug reports
Include:
1. Chrome version and operating system.
2. Steps to reproduce.
3. Expected result and actual result.
4. Whether the issue happens on one site or multiple sites.
5. Relevant console errors with sensitive values removed.

## Pull requests
- Keep changes focused and explain the user-visible impact.
- Avoid adding dependencies unless necessary.
- Do not add permissions without explaining why they are required.
- Test the extension through `chrome://extensions` and on at least one ordinary website.
- Update the README and privacy notes if behavior, permissions, storage, or network access changes.
