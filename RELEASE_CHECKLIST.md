# Release checklist

- [ ] Load the extension from the repository in a clean Chrome profile.
- [ ] Verify all manifest permissions are necessary.
- [ ] Test activation, four modes, CSS preview/undo, copy actions, and Pockets.
- [ ] Verify the original keyboard shortcuts are unchanged.
- [ ] Test on multiple websites and a long page.
- [ ] Review console errors and remove debug logs.
- [ ] Confirm whether the extension makes network requests.
- [ ] Confirm privacy/storage behavior matches the README and any store disclosures.
- [ ] Add real screenshots/GIFs captured from the working extension.
- [ ] Update version and changelog.
- [ ] Create a GitHub release with a tested ZIP.
